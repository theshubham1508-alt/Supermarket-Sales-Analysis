# 🛒 Supermarket Sales Analysis

## 📌 Project Overview

This project analyzes supermarket sales data to identify sales trends, customer purchasing patterns, and overall business performance.

The analysis was performed using Python and Excel with the help of data cleaning, exploratory data analysis, and visualization techniques.

## 🎯 Objectives

- Analyze overall supermarket sales performance
- Understand customer purchasing behavior
- Analyze sales by product line
- Study sales trends
- Compare sales across different categories
- Identify useful business insights from the dataset

## 🛠️ Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Microsoft Excel

## 📂 Project Files

| File | Description |
|------|-------------|
| `Supermarket_Sales_Analysis.ipynb` | Complete Python analysis and visualizations |
| `SUPER MARKET DATA.xlsx` | Dataset used for analysis |

## 🔍 Analysis Process

### 1. Data Loading
The supermarket sales dataset was imported into Python using Pandas.

### 2. Data Cleaning
The dataset was checked for:
- Missing values
- Duplicate records
- Incorrect data types
- Data consistency

### 3. Exploratory Data Analysis

Different aspects of the dataset were analyzed, including:

- Sales performance
- Product line analysis
- Customer behavior
- Payment methods
- Gender-wise analysis
- Branch-wise performance
- Rating analysis

### 4. Data Visualization

Visualizations were created using Matplotlib and Seaborn to understand patterns and trends in the data.
